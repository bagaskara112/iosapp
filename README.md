# MoodKita 🐼🦊

Aplikasi mobile (React Native & Expo) untuk pasangan agar bisa saling memantau *mood* harian secara *real-time*.

## Fitur Utama ✨
- **Sinkronisasi Real-time**: Menggunakan Supabase untuk mendeteksi perubahan *mood* pasangan secara instan.
- **Kalender Mood**: Melacak riwayat *mood* pasangan sepanjang bulan.
- **Haptic Feedback**: Getaran yang menenangkan saat mengirim pelukan virtual.
- **UI Imut & Estetik**: Tampilan warna-warni pastel yang nyaman di mata.

## Cara Menjalankan Aplikasi Lokal 🚀
1. Lakukan `npm install`
2. Atur konfigurasi `.env` Anda dengan referensi rahasia `EXPO_PUBLIC_SUPABASE_URL` dan `EXPO_PUBLIC_SUPABASE_ANON_KEY`.
3. Jalankan `npx expo start -c`
4. Buka aplikasi menggunakan Expo Go di iPhone / Android Anda.
